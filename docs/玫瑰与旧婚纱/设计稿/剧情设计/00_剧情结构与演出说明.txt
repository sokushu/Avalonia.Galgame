《玫瑰与旧婚纱》剧情结构与演出说明
本版性质：依据原故事重新扩写的可阅读Galgame剧本。原始故事文件保留；本目录中的剧本与路线说明为本版叙事依据。其他人物、舞台与CG文件可沿用人物外观和基础构图，其旧段落引用以本目录场景编号为准。

一、阅读顺序与文件
01_共通剧情.txt：冬天相遇至十一月底收到信，共通线正文。
02_分支与结局.txt：选项、去向、条件和制作核对表，仅供设计阅读。
03_分支A_两人的尺寸.txt：一起重谈生活、试着同住、旧店危机与共同经营、春日量身；好结局。
04_分支B_合身的告别.txt：认真试行异地相处、重逢后的短暂幸福、承认生活方向不同、告别及多年后重逢；一般结局。
05_分支C_没有日期的以后.txt：回避具体安排、一次真实的重逢、迟迟未被回答的邀请、逐渐失联与未交付的外套；坏结局。
单次游玩：01共通 → 03、04、05中的一个 → 片尾。三条分支互斥，没有结局后自动回到共通线的情况。首次游玩即可进入任一分支，无解锁要求。

二、阅读量
按共通与所选分支合计约一小时规划，三条分支各准备约半小时的文本体量。实际核对：共通正文约1万个中文字，单个分支约6,800—7,000个中文字；按每分钟240—300个中文字粗估，共通约33—42分钟，分支约23—30分钟，完整路线约56—71分钟。计时只包括该次路线实际显示的正文，不把互斥选项反应、其他结局和制作说明相加。纯阅读速度、自动播放间隔、语音和玩家停留会改变时长，最终还需要在游戏中实测。不能把文件字节数当作阅读字数。详细数字见02_分支与结局.txt。
写作重点：工作和吃饭等日常构成关系；恋爱中的期待与羞耻、对死者的怀念与对生者的亏欠都允许存在；情绪由具体行动发展，不让人物每次争执后立即把道理讲透。

三、剧本格式
【场景】时间、地点、BG与视角。
【演出】音效、转场、立绘动作、CG落点；不作为对白框正文显示。
【旁白·叶照】叶照第一人称内心和观察；默认主视角。
【旁白·见月】明确切换到唐见月的第一人称；不得在同一段内无提示跳视角。
人物名：对白。引号内的手机文字、信与旧对白均标明来源。
【选项】仅三处。显示供玩家选择的句子，不显示设计标签、路线名及结局性质。
【条件演出】仅播放该玩家所选反应；随后回到指定场景。正文中不存在让玩家自行补写的空白。
【本章收束】下一场的行动、声音或物件承接，不属于额外选项。

四、三个选择节点
Q1，共通纱S03：见月说起丈夫送错工具。
1A「那个工具，后来用上了吗？」→ 阅读Q1A对话 → 纱S04；记录“听过旧事”。
1B「下次先给我一张礼物清单吧。」→ 阅读Q1B对话 → 纱S04；记录“用玩笑靠近”。
两者都是表达关心的方式；改变共通与分支的回应，不增设攻略线，不用好感数值判断爱意。

Q2，共通纱S06：在门外等过一下午之后。
2A「我今天很难受。能陪我坐一会儿吗？」→ 阅读Q2A对话 → 纱S07；记录“说出门外的委屈”。
2B「今天先吃饭吧。你中午没吃东西。」→ 阅读Q2B对话 → 纱S07；记录“把谈话留到后来”。
2B不是当场惩罚选项；争执或分支中会让叶照承认自己曾经隐瞒。2A也不会令长期现实困难提前消失。

Q3，共通纱S10：见月寄来有日期的邀请，叶照也得到外地项目续约邀请。
3A「我回去。先把一起生活的事谈完。」→ 03_分支A_两人的尺寸.txt，从A01起；最终好结局。
3B「我想留下工作，也想认真试着和你走下去。」→ 04_分支B_合身的告别.txt，从B01起；最终一般结局。
3C「等忙完这一阵，我们再谈吧。」→ 05_分支C_没有日期的以后.txt，从C01起；最终坏结局。
Q3代表该路线持续采取的生活方式，不是一句话立即改变命运。A仍需经营；B会真实尝试，结局源自她们无法接受同一种长期安排；C经历多次有机会开口却退回安抚的过程。前两次选择改变台词记忆，不会封锁Q3。
全部选项位于共通线；分支内没有第四个互动选项。人物主动决定、商量日期与回答电话均为固定剧情，不呈现菜单。

五、节奏与场景连接
共通：抢修婚纱 → 送照片 → 借衣与午饭 → 量尺寸与旧婚纱 → 夏夜接吻 → 亲友质问 → 暴雨与看房 → 合同争执 → 分开后的日常 → 收信分流。
季节变化由订单、修衣交付、花瓶与日历推进，时间字幕在承接动作之后出现。跨月前先交代等待、反复见面与关系的变化；不以“后来她们熟了”代替发展。
分支A：回信 → 回店 → 试住 → 店顶维修导致临时搬工作台 → 家庭关系再遇挫折 → 事业取舍与私人合照 → 确认租房 → 春日新衣。
分支B：回信 → 两边的生活 → 探访 → 两周试住 → 决定告别 → 物品归还 → 春末想念的电话 → 2033年重逢。
分支C：含糊回信 → 延期 → 短暂见面 → 展览邀请落空 → 向亲友承认关系 → 谈话中再次回避 → 联系中断 → 2033年发现未交付的外套并归还。

六、连续性
时间：2029年1月18日相遇；10月至11月驻留；11月末Q3；各线由2029年冬继续。A尾声2030年春；B、C尾声2033年冬。
地点：雁汀与外地驻留城市；后者不另设城市名称。新工作室纱BG08在雁汀，是工作场所，不能直接当住宅使用；A同住地点是旧店楼上的生活间，摄影工作另有空间。
道具：开篇两枝玫瑰留成干花；后续鲜花不替换其物件身份。旧婚纱是见月自己曾穿过的婚纱，保留在楼上衣柜。主相机随叶照工作；旧备用相机因背带待修暂存衣坊，备用镜头盖与深棕外套也留在那里。
外套：共通只缝好右内侧镜头盖口袋，肩线须本人试穿才完成。A、B完成并交付；C至2033年仍未交付。A、B旧备用相机一并取回，C留存后最终归还。
哀伤：不以陈牧的遗书、梦中批准或婆婆完全谅解推动爱情；保留真实的旧婚姻和见月对女性的心动。程雪只在回忆出现，不加入前任争夺支线。
美术：沿用纱BG01—10和纱CG01—10；新段落使用已有背景的雨天、夜间与布置后差分。手机、信和旧照片可用普通文字演出，不要求新增独立CG。
