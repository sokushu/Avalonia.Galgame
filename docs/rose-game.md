# 玫瑰与旧婚纱

基于 MonoGalGame 的独立桌面 Galgame。叶照是 28 岁的婚礼摄影师，唐见月是 32 岁的婚纱裁缝；故事从 2029 年冬天一场婚礼的意外相遇开始。

## 启动

```powershell
dotnet run --project examples/MonoGalGame.Rose
```

Windows 0.14 原生发布程序位于 `artifacts/rose/v14-win-x64/RoseAndOldWeddingDress.exe`，直接双击启动。完整压缩包为 `artifacts/rose/RoseAndOldWeddingDress-v14-win-x64.zip`。分发时保留整个目录，其中包含 SDL、OpenAL、字体、插画、配乐与剧本。

在 IDE 中使用 `examples/MonoGalGame.Rose` 作为启动项目。原来的《春日来信》示例仍可以独立启动。

## 剧本

叙事依据为 `docs/玫瑰与旧婚纱/设计稿/剧情设计/` 下的四份正式正文：共通线、分支 A《两人的尺寸》、分支 B《合身的告别》、分支 C《没有日期的以后》。原始故事与设计文件保留原样。

游戏保留全部 1,085 段原文对白与旁白，生成 1,171 个剧情节点。共通线只有三次选择：前两次记录不同的回应并改变后续对白，第三次决定独立路线。三条路线均可在首次游玩进入；分支内不添加选择，也不会在结局后串入另一条路线。单线阅读量依据剧本约为一小时，实际游玩时间受阅读速度与停留影响。

制作标签、分流箭头、条件说明不会出现在对白框。章节、时间、地点与当前叙述视角显示在阅读界面；单人、双人和三人立绘按实际在场人物与剧情插画切换。周素琴、唐玉芬、刘庆、秦嘉、罗小安、潘成和贺晴有独立立绘，其他配角对白仍保留姓名。夜间使用对应背景和人物色温，断灯及冷白工作灯另做环境处理。

开发时可以重新编译剧本，玩家运行时不需要 Python：

```powershell
python scripts/build_rose_story.py
python scripts/build_rose_story.py --check
```

`Game/Stories/source-manifest.json` 记录四个源文件、演出表和编译器的 SHA-256、原文段数及生成节点数，并区分原设计十三张与补充二十三张 CG。`scripts/rose_staging.py` 明确记录每场的日期、光线、实际在场人物，以及由原文定位的转场；编译器要求每个定位恰好匹配一次，并要求全部三十六张 CG 实际出现在可阅读节点。`Game/Stories/staging-manifest.json` 可按原文文件与行号逐段核对演出。`--check` 检查已提交的 JSON 是否与源剧本及演出表一致。

## 美术与界面

- 全幅双人主视觉、双行书名、右侧六列竖排菜单，支持鼠标、方向键、Tab 与 Enter。
- 叶照二十三张、唐见月十九张、周素琴四张、唐玉芬两张、刘庆两张、秦嘉两张、罗小安一张、潘成一张、贺晴两张，共五十六张 1024 × 1536 的透明 PNG 立绘保留真实 Alpha，包含日常、工作、情绪与动作。刘庆有领看时的钥匙及收起钥匙后的确认姿态，秦嘉有专业倾听与思考表情，唐见月有手工收边、携行李与饭盒的动作，贺晴区分修补前后的表情和裙摆状态，叶照有温和与紧绷的贴耳通话动作。2033 年造型与原有终章 CG 对齐，区分新外套的携带、穿上和旧外套的落泪、消息动作。
- 五十五张背景，覆盖原设计十处基本场景及搬家后的新住处、驻留公共工作区、五处主要室内夜景、楼上整理前后与九月雨夜清晨，以及白天小巷、临时摄影工作室和布置后的共同工作室。另有一月漏雨、维修后日夜、临时工作室夜景、会馆走廊、驻留室春夏冬日日夜、新住处日夜、四年后的前厅及冬季工作间日夜和小巷。另有冬日阳台和摄影室冬日日夜，本轮补齐十月楼上整理前后秋景和关灯后的空房。冷白工作灯的夜景不重复叠加暗色。

五首原创合成配乐位于 `Game/Audio/`，分别用于冬日、衣坊日常、心动、距离与来信。生成方法保存在 `scripts/build_rose_music.py`，使用 NumPy 生成音色；这些是合成器配乐，未使用下载录音。当前没有角色配音。

## 操作与存档

左键、Space 或 Enter 推进，数字键 1–3 或上下方向键选择。F5 快速保存、F9 快速读取，A 自动阅读，Ctrl 快进，L 历史，H 隐藏界面，滚轮向上回退，Esc 暂停，F11 全屏。底部工具栏也可操作存读档、自动与历史。

有六个手动存档和一个独立快速存档。默认玩家数据位于 `%LOCALAPPDATA%/MonoGalGame/rose-and-old-wedding-dress/`，与原示例和游戏安装目录分离。可用 `--data-dir <路径>` 指定数据目录。

标题的“继续阅读”优先返回当前会话；重新启动后会查找最新的有效快速或手动存档，自动跳过损坏、不兼容的存档。画廊收集位于同一目录的 `reading-progress.json`。
